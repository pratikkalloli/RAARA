HOW THIS DEMONSTRATION WORKS

A transparent local workflow

User question→Query processing→Local retrieval→Provenance validation→Answerability check→Answer + citations
or abstention

Retrieval
Local cosine similarity over a process-memory representation of this corpus. Similarity scores are not probabilities or confidence estimates.

Answer generation
Deterministic local templates and calculations. No live OpenAI API or LLM is used.

Corpus status
All 28 policy records are project-authored generic examples. Official PES University regulations are not verified in this corpus.
